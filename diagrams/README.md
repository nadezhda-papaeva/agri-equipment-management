# Диаграммы бизнес-процессов

В разделе представлены BPMN-диаграммы процесса технического обслуживания и замены запасных частей сельскохозяйственной техники.

Диаграмма AS-IS отражает текущее состояние процесса, выявленное в ходе обследования предприятия.

Диаграммы TO-BE отражают мои аналитические рекомендации по изменению процесса и не являются описанием уже внедрённого решения.

## AS-IS — текущее состояние процесса

![BPMN AS-IS](bpmn-as-is-maintenance.png)

Диаграмма отражает текущий процесс обслуживания и ремонта техники.

Основные особенности текущего процесса:

- ежедневная проверка состояния техники;
- ручная передача информации о неисправности;
- определение необходимой детали;
- проверка наличия запасной детали;
- ручной поиск поставщиков при отсутствии нужной детали;
- сравнение вариантов закупки по цене, наличию, срокам поставки и качеству;
- риск простоя техники при невозможности оперативной закупки.

## TO-BE — плановая замена деталей

![BPMN TO-BE — плановая замена](bpmn-to-be-planned-maintenance.png)

В рамках аналитических рекомендаций предложен целевой процесс планового обслуживания техники.

Предлагаемые изменения:

- автоматический контроль сроков плановой замены деталей;
- предварительное уведомление о приближении срока замены;
- проверка наличия необходимой детали в запасе;
- отображение доступных поставщиков при отсутствии детали;
- заблаговременная закупка необходимых запасных частей;
- фиксация выполнения плановой замены;
- обновление истории обслуживания;
- автоматический расчёт следующей плановой даты замены.

## TO-BE — внеплановый ремонт

![BPMN TO-BE — внеплановый ремонт](bpmn-to-be-unplanned-maintenance.png)

Для работы с внезапными неисправностями предложен отдельный целевой процесс.

Предлагаемые изменения:

- фиксация неисправности и требуемой детали в системе;
- централизованная проверка наличия запасной части;
- отображение информации о поставщиках;
- использование единой базы данных по закупкам и запасным частям;
- фиксация истории ремонта и замены деталей;
- сокращение количества ручных действий при поиске информации.

## Аналитический вывод

Диаграммы TO-BE сформированы на основании проблем и ограничений, выявленных при анализе текущего процесса AS-IS.

Предложенные изменения направлены на переход от преимущественно реактивного обслуживания техники к более плановому и проактивному управлению сроками замены деталей, запасами и закупками.

TO-BE представляет рекомендуемое целевое состояние процессов. Фактический эффект предложенных изменений требует проверки после реализации и внедрения решения.
