# Диаграммы бизнес-процессов и системы

В разделе представлены BPMN- и UML-диаграммы, подготовленные в рамках обследования бизнес-процессов сельскохозяйственного предприятия и проектирования системы учёта и обслуживания техники.

## 1. BPMN AS-IS — текущий процесс обслуживания техники

[Открыть BPMN AS-IS](bpmn-as-is-maintenance.png)

Диаграмма отражает существующий порядок выявления неисправностей, проверки наличия запасных частей, поиска поставщиков и организации ремонта.

Основное внимание уделено ручным операциям, зависимости от доступности запчастей и рискам простоя сельскохозяйственной техники.

## 2. BPMN TO-BE — плановое обслуживание

[Открыть BPMN TO-BE: плановое обслуживание](bpmn-to-be-planned-maintenance.png)

Диаграмма описывает предлагаемый процесс плановой замены деталей с использованием информационной системы.

Предусматриваются контроль регламентных сроков, заблаговременное информирование о предстоящих заменах, проверка запасов, подготовка закупки и обновление истории обслуживания.

Цель предлагаемых изменений — снизить риск простоев техники из-за несвоевременной замены деталей.

## 3. BPMN TO-BE — внеплановый ремонт

[Открыть BPMN TO-BE: внеплановый ремонт](bpmn-to-be-unplanned-maintenance.png)

Диаграмма описывает предлагаемый порядок действий при обнаружении неисправности техники.

Предусматриваются регистрация неисправности, проверка наличия необходимой детали, использование информации о поставщиках, организация закупки при необходимости и фиксация выполненного ремонта.

## 4. Диаграмма вариантов использования (Use Case Diagram)

[Открыть Use Case Diagram (PDF)](Use%20Case%20%20Diagram.pdf)

Диаграмма отражает основные пользовательские сценарии предлагаемой системы и взаимодействие двух ролей: сотрудника (водителя) и управляющего.

Представлены функции учёта техники, контроля обслуживания и запасов, регистрации неисправностей, планирования замен и организации закупок.

---

## Статус аналитической работы

BPMN AS-IS отражает текущий процесс, выявленный в ходе обследования предприятия.

BPMN TO-BE, Use Case Diagram, UML Class Diagram и Object Diagram представляют предлагаемые решения по оптимизации обслуживания техники и управлению запасными частями.

Модели являются результатом аналитической работы и не описывают уже внедрённую информационную систему.
