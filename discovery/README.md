# Обследование бизнес-процессов

В данном разделе представлены результаты обследования
сельскохозяйственного предприятия.

В рамках аналитической работы были:
- проведены интервью с заказчиком;
- изучены существующие бизнес-процессы (AS-IS);
- выявлены проблемы и операционные риски;
- определены приоритетные направления оптимизации;
- сформированы аналитические рекомендации;
- предложено целевое состояние процессов (TO-BE).
